## Bugs encontrados

### BUG-1: Bucket avatars no existe en produccion
- **Severidad:** ALTA — bloquea subida de foto de perfil, que bloquea perfil_completo, que bloquea Consulta Inmediata.
- **Root cause:** El codigo (src/app/api/medico/foto/route.ts linea 36) referencia bucket avatars pero nunca se creo en Supabase Storage. Los otros buckets (credenciales-medicos, consultas-temp, firmas-medicos) si existen.
- **Fix temporal:** Bucket creado manualmente via admin client durante QA.
- **Fix definitivo:** Migracion SQL + script de bootstrap que cree el bucket.
- **Archivos:** src/app/api/medico/foto/route.ts

### BUG-2: HEIC no soportado — iPhone no puede subir foto
- **Severidad:** ALTA — afecta a todo usuario iPhone (>60% del target en Argentina).
- **Root cause:** Backend whitelist: ALLOWED_TYPES = ["image/jpeg", "image/png", "image/webp"]. iPhone toma fotos en HEIC por defecto. El frontend acepta image/* pero el backend rechaza HEIC.
- **Fix propuesto:** Conversion server-side HEIC->JPEG usando sharp.
- **Archivos:** src/app/api/medico/foto/route.ts (lineas 18-21)

### BUG-3: sandbox_init_point no se usaba para cuentas MP test
- **Severidad:** MEDIA — solo afecta testing con sandbox, no produccion real.
- **Root cause:** crear-v2/route.ts siempre retornaba pref.init_point. Cuando el medico tiene cuenta MP sandbox (live_mode: false), MP devuelve sandbox_init_point.
- **Fix aplicado:** Commit 25021bb — usa sandbox_init_point cuando live_mode === false.
- **Estado:** FIXEADO. El sandbox de MP tiene problemas propios de redirect loops que son de MP.
- **Archivos:** src/app/api/pago/crear-v2/route.ts

### BUG-4: Indicador de perfil incompleto no es claro
- **Severidad:** BAJA (UX) — no bloquea funcionalidad pero confunde al usuario.
- **Sintoma:** Dashboard muestra 67% con lista de campos faltantes (dot naranja) pero:
  - (a) Domicilio ya estaba completo, aparece como faltante (bug de data upstream)
  - (b) Los dots naranjas se confunden con sugerencias grises
  - (c) No hay indicacion inline en cada campo del perfil
- **Spec UX:** docs/ux/PERFIL_PROGRESO_INDICADORES_2026-05-27.md
- **Archivos:** PanelProgresoPerfil.tsx, PerfilClient.tsx

### BUG-5: "Dashboard" en lugar de "Volver" en back navigation
- **Severidad:** BAJA (UX)
- **Sintoma:** Pantalla de perfil muestra "← Dashboard" como link de retorno. Patron universal humano: "← Volver".
- **Archivos:** PerfilClient.tsx y otras pantallas secundarias
